About Me

This is what I do.

Hey! I’m Rishab

a computer science student and someone who is constantly curious about technology and how things work. I started getting interested in programming because of a simple question: “How does all of this actually work?” That curiosity eventually turned into writing code, breaking things, fixing them, and spending far too much time trying to understand why something that should work… doesn’t. 😄 Currently, I’m exploring different areas of computer science, including Python, artificial intelligence, machine learning, cybersecurity, web development, and software engineering. I enjoy experimenting with technologies rather than limiting myself to a single field. Sometimes that means building a web application, sometimes training a machine-learning model, and sometimes completely breaking my Linux installation while trying something new.

When I’m not coding, I enjoy reading, writing, and exploring the world around me. I also like to share what I learn with others.

What I’m Learning

I believe that programming is less about memorizing syntax and more about learning how to think, solve problems, and build things. Right now, I’m working on improving my understanding of:
  • 🐍 Python and programming fundamentals
  • 🧠 Artificial Intelligence & Machine Learning
  • 💻 Data Structures & Algorithms
  • 🌐 Web Development
  • 🔐 Cybersecurity
  • 🐧 Linux and open-source software
  • ⚙️ Software development and system design

    • I’m still learning, and I definitely don’t have everything figured out. That’s actually one of the reasons I started writing. Why This Blog? The internet is full of tutorials that show you the final answer but rarely show you the messy process of getting there. I want this blog to be a little different. Here, I document things I learn while building projects, experimenting with technology, solving problems, and occasionally making spectacular mistakes. You might find tutorials, project breakdowns, technical explanations, experiments, notes, and random things that I found interesting. Some posts will be beginner-friendly. Others might go deeper into the technical details. The goal is simple: Learn something. Build something. Break something. Understand why it broke. Then write about it. Beyond Code

    Technology isn't the only thing I’m interested in. I enjoy exploring random ideas, learning about how the world works, and going down those internet rabbit holes that start with one innocent question and somehow end three hours later. This blog is therefore not limited to programming. If I find something fascinating enough to learn about, there’s a good chance I’ll write about it. The Journey I’m still at the beginning of my journey in technology. There will be things I don't know, projects that fail, code that needs rewriting, and plenty of concepts that take several attempts to understand. And that's fine. I don't want this website to pretend that I already know everything. I want it to document the process of becoming better at it. If something I write helps you understand a concept, solve a problem, or inspires you to build something yourself, then the blog has done its job. Thanks for stopping by.
